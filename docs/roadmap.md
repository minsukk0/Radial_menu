## 단계별 계획

| Phase | 범위 | 완료 기준 |
|---|---|---|
| **0. 환경 + 실험** | `rustup`, MSVC 빌드 도구, Tauri CLI 설치. 아래 "먼저 할 실험" 5가지 | 실험 결과를 이 문서에 기록하고 스택 확정 |
| **1. 설정 코어 + CLI** | Cargo workspace, `radial-core`(모델·검증·저장·해시), 스키마·TS 타입 생성, `rmctl`(path / schema / validate / list / category / item), `examples/menu.example.json` | 에이전트가 `rmctl`로 항목을 넣고 `validate`가 통과 |
| **2. 메뉴 화면 + 입력** | `radial-layout.ts` 이식, `menu-standalone.html` 렌더링 이식, 훅 스레드, `gesture` 상태 머신, 메뉴 창 표시, 설정 감시·다시 읽기 | Ctrl+휠클릭으로 열고, 가리키고, Ctrl을 떼면 선택한 항목 id가 로그에 찍힘. 시안과 같은 모양·모션 |
| **3. 실행기** | `launcher`(관리자 / 권한 낮추기 / 폴백), 앱·폴더·시스템 실행기, 자리표시 수집(`context`), 터미널 새 창 열기·명령 실행, 끝나면 알림 | 분류 4종이 모두 실행됨. 브라우저·앱은 일반 권한으로 뜸 |
| **4. 승인 + 에이전트 문서** | 승인 기록·승인 창, `ProgramData` 권한 검사, 메뉴의 "승인 필요" 표시, `AGENTS.md`, (선택) 전역 스킬 | 에이전트가 넣은 관리자 항목이 승인 후에만 관리자로 실행됨 |
| **5. 항목 추가 창** | Svelte로 `add-item.dc.html` 이식, 분류별 입력란, 자리표시 칩, 찾아보기, 실행 중인 앱에서 고르기, 테스트 실행 | 손으로 분류 4종의 항목을 추가·저장 |
| **6. 마무리** | 트레이, 설정 창, 제외할 프로그램 목록, 전체 화면 예외, `install.ps1` / `uninstall.ps1`, 배포 빌드 | 설치 후 재부팅하면 관리자로 자동 상주 |

## 먼저 할 실험 (Phase 0)

핸드오프 §9.4의 네 가지에 입력 방식 확인을 더했다. 스택 판단은 공식 문서 근거이고 아직 Windows에서 돌려 본 결과가 아니다.

| # | 확인할 것 | 통과 기준 |
|---|---|---|
| 1 | 투명 창 위의 반투명 원판이 바탕 화면과 제대로 섞이는가 | `decorations: false`, `transparent: true`, `shadow: false`에서 원판 바탕이 70% 검정으로 비침 |
| 2 | 포커스를 뺏지 않으면서 호버·클릭을 받는가 | 메모장에 입력 중 메뉴를 띄워도 메모장 캐럿이 유지되고, 메뉴 칸 호버·클릭이 동작 |
| 3 | 휠클릭부터 메뉴가 보일 때까지 즉시인가 | 미리 만든 숨김 창 기준 체감 지연 없음 (목표 50ms 이하) |
| 4 | 관리자 창이 앞에 있을 때 훅이 동작하는가 | 관리자 PowerShell 창 위에서 Ctrl+휠클릭 동작 (앱을 관리자로 실행한 상태) |
| 5 | Ctrl 뗌으로 실행하는 흐름이 자연스러운가 | Ctrl 뗌 → `menu:commit` → 응답까지 지연 없음, 휠 누름·뗌 짝이 맞아 뒤 프로그램이 이상 동작하지 않음 |

## 미결정 사항

**입력 방식**
- [ ] 분류만 가리킨 채 Ctrl을 떼면 닫기로 했다. 대신 "메뉴를 그대로 열어 두기"가 나은지 써 보고 정한다.
- [ ] 브라우저의 Ctrl+휠클릭(링크를 백그라운드 탭으로)과 겹친다. 제외할 프로그램 목록을 기본으로 둘지.
- [ ] 메뉴가 열린 동안 휠 굴림을 분류 넘기기에 쓸지 (지금은 삼키기만 함).

**설정**
- [ ] 같은 종류의 분류를 여러 개 둘 수 있게 할지 (예: "앱"과 "게임" 둘 다 `app`). 지금 문서는 허용.
- [ ] 한 분류의 항목 수 상한 (핸드오프 §8: 시안은 10개까지).

**핸드오프 §8에서 넘어온 것**
- [ ] 하위 링에 "추가" 칸을 항상 붙이는가 (지금은 붙임)
- [ ] 그리지 않은 화면: 분류 추가, 항목 고치기·지우기·순서 바꾸기, 설정 창, 트레이 메뉴, 스크립트 완료 알림
- [ ] 화면 가장자리에서의 메뉴 위치 (지금은 중심을 안쪽으로 옮김)
- [ ] 게임·전체 화면 프로그램에서 끌지

**도구**
- [ ] 창 화면 프레임워크: Svelte 5(제안) vs React
- [ ] 다른 작업 공간용 전역 스킬을 만들지
